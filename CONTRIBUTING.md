# Contributing

Run `npm ci` and `npm run check`. Changes to synchronization must keep edits private until both partners complete cross-editing; add regression coverage when changing that boundary. Keep AI hypotheses, self-confirmed descriptions, and partner interpretations distinct.

Use fictional conversations for examples and tests. Never commit participant records, model keys, local environment files, or logs. Keep Chinese and English on the same workflow implementation. Document departures from the manuscript in `docs/PAPER_TO_CODE.md`.
