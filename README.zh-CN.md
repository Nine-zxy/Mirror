# ASIDE · 共镜

**从冲突参与者到共同观察者：双人旁观反思（Dyadic Spectator Reflection）**

[English](README.md) · [论文与代码对应](docs/PAPER_TO_CODE.md) · [复现步骤](docs/REPRODUCTION.md) · [发布状态](docs/RELEASE_STATUS.md)

ASIDE 将对话重建成可回看的场景，让双方先确认自己的感受，再独立编辑对对方的理解，最后同步揭示并比较两种视角。AI 生成的是可修改的假设，不是对他人内心的事实判断。

这是整理并修正过的研究代码候选版，不是原始实验部署的冻结快照。不含参与者数据，也不能用虚构示例复现论文的统计结果。

## 项目介绍网页

应用首页提供中英双语项目介绍、三阶段交互可视化、代码模块说明、快速运行命令，以及单人和双人演示入口。点击阶段卡片可以切换视角示意；研究、运行和发布说明可在页面内打开。页脚提供 GitHub 仓库入口。

## 安装与启动

安装 Node.js 22.12 或更新版本，在本目录运行：

```sh
npm ci
npm run dev
```

打开 <http://localhost:5173>，选择中文或 English。首页的“晚餐的约定”是新编写的虚构案例，无需密钥即可体验。

- 单人浏览：直接进入示例，检查自己的确认、对他人的编辑、共同观看与差异卡片。
- 双人演示：在同一首页先打开 A，再打开 B；两个标签页即可。双方都完成编辑才会揭示。
- 两台设备：使用 `npm run dev:lan`，两台设备访问主机的局域网 IP 与 5173 端口。

```sh
npm test
npm run build
npm run preview
npm run check
```

`preview` 使用 4173 端口，同时启动同步服务器。不要同时运行两套占用 3001 端口的服务器。

## 可选 AI 模式

复制 `.env.example` 为 `.env.local`，填入 `GEMINI_API_KEY`，重启。密钥只由本地代理读取，不要使用 `VITE_` 前缀保存密钥。默认模型为论文所述的 `gemini-2.5-flash`；改用其他模型时，应明确说明这是复现差异。

启用后，对话及上下文会发送给 Google API。未配置密钥时使用确定性的演示/回退场景，不代表真实完成了 AI 分析。真实模型请求、可用性和生成质量不由离线测试保证。

## 本次整理边界

保留论文对应的核心程序、提示词、结构化场景、双人同步和差异比较；排除参与者情境、日志、转录、环境密钥、论文草稿、视频及旧 Git 历史。默认关闭行为记录、自动上传和浏览器日志备份。原位图素材缺少明确再分发记录，本版采用代码绘制的人物和场景，因此不承诺与论文截图逐像素一致。

首页和虚构示例已支持中英切换；历史研究操作页面仍有混合语言。完整双语界面与视觉整理属于下一阶段，目前不宣称已经完成。

本版用于本机或可信局域网复现，尚不是带认证、权限管理的公网服务。房间码用于配对，不是访问凭据。
